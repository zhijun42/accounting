# Review and data rules

- Code and documentation changes must be reviewed and explicitly confirmed by the user before running git commit.
- Do not push without the user's authorization. A request to implement or import data is not permission to commit or push.
- Keep original statements, databases, import reports, audit data, and derived personal data local and ignored by Git.
- Run the project's Makefile targets for verification. Do not replace them with an assumed equivalent command.
